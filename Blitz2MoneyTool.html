Quick start

  1. Back up your entire PS3 save folder first. Do not experiment on your only copy.
  2. On Windows, use Bruteforce Save Data 4.7.5 to decrypt the save: select the Blitz save, choose Decrypt PFD > Decrypt All, and confirm.
  3. Select the now-decrypted BSAV0.SAV above. If this tool detects no campaigns, stop; you may have selected an encrypted file, the wrong file, or an unsupported save format.
  4. Enter the cash amount. $8,500,000 is the tested default and is enough to buy all facility upgrades with a small buffer. The format's observed maximum is $16,777,215.
  5. Click Patch all detected campaigns. The tool downloads a new file named BSAV0.SAV. Replace the decrypted working copy with that file.
  6. Back in Bruteforce, use Update PFD > Full update and agree to encrypt the files. If Encrypt PFD > Encrypt decrypted files is available, run it. Then use Verify PFD and finally Rebuild > Rebuild Full.
  7. Copy the finished save folder to USB:\PS3\SAVEDATA\, insert the USB in the PS3, then use Game > Saved Data Utility (PS3) > USB Device > Blitz: The League II > Triangle > Copy.
  8. Load every campaign you patched, buy something, save, quit, and reload once before deleting any backup.

Bruteforce setup help: see the included README.md / START_HERE.txt. The public walkthrough used for the Bruteforce portion is The Project Lounge's PS3 save guide.

Important

This tool does not decrypt or resign PS3 saves. It edits the game's decrypted BSAV0.SAV and repairs the game's own internal checksum. Bruteforce still handles the Sony PS3 encryption/PFD steps.

Verified: BLUS30203. Other regions are untested. The tool intentionally preserves the game's existing money-spent counters and changes current cash only. If cash-on-hand ever exceeds the observed 24-bit limit of $16,777,215 during play, behavior is not yet documented; keep backups.
