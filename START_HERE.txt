BLITZ: THE LEAGUE II PS3 SAVE EDITOR v1.3
=========================================================

Verified format:
BLUS30203 (North American PS3)

MAIN FILE:
Blitz2SaveEditor.html

QUICK WORKFLOW
--------------

1. Back up your entire PS3 save folder.

2. Copy the save from PS3 to USB.

3. On Windows, open the save in Bruteforce Save Data.

4. Decrypt the save / decrypt all.

5. Open Blitz2SaveEditor.html in a desktop browser.

6. Load the decrypted BSAV0.SAV.

7. Configure each campaign independently:
   - optional cash amount;
   - Juice of the Week;
   - optional zero-risk cleanup;
   - Juice checkbox for ordinary players;
   - optional "Apply effects of TGH?" checkbox.

8. Click:
   Build patched BSAV0.SAV

9. Replace the decrypted working BSAV0.SAV with the generated file.

10. In Bruteforce:
    - update PFD / full update;
    - encrypt decrypted files if needed;
    - verify PFD;
    - rebuild full.

11. Copy the finished save back to PS3 through normal Saved Data Utility.

IMPORTANT
---------

- New editor-created juice records use zero Team Risk.
- Juice insertion remains capped at three players.
- Franchise juicing is enabled experimentally and mirrors the juice record into both real Franchise player-state copies.
- "Apply effects of TGH?" is NOT juicing.
  It only adds +5 to one random mapped visible stat modifier.
- You can use the TGH effect and juicing independently.
- Native TGH did not produce its advertised +5 in the project's controlled
  development-console tests. We do NOT know whether that is universal.
- Always keep an untouched backup.

The editor works entirely offline.

TGH SELECT-ALL
--------------

Each campaign has a "Select All TGH Effects" button that checks the custom
TGH-effect option for every detected roster player, including backups.

This does not select anybody for Juice.
